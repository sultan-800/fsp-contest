# ФСП Контест

Платформа Федерации спортивного программирования для проведения онлайн-соревнований:
профили спортсменов, соревнования, контесты с задачами, отправка и ручная проверка решений,
итоговые таблицы и единый рейтинг.

**Стек:** Python 3.10+ · Django 5.1 · SQLite · WhiteNoise. Без внешних CDN — шрифты и скрипты размещены локально.

---

## Быстрый запуск

**Windows:** двойной клик по `run.bat`
**Linux / macOS:** `./run.sh`

Или вручную:

```bash
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate          # создаёт БД, справочники и аккаунт организатора
python manage.py seed_demo        # демо-данные (пересоздать: --reset)
python manage.py runserver
```

Откройте http://127.0.0.1:8000

| Роль | Логин | Пароль |
|---|---|---|
| Организатор (создаётся автоматически) | `organizer` | `Organizer#2026` |
| Спортсмен | `ivanov` (а также `magomedov`, `alieva`, `gasanov` …) | `Athlete#2026` |

Вход возможен по логину или email. Спортсмены регистрируются самостоятельно.
Для локальной отладки: `DJANGO_DEBUG=1 python manage.py runserver`.

Тесты сквозного сценария и безопасности: `python manage.py test`

## Сценарий демонстрации (7 обязательных показов)

1. **Организатор** → «Панель организатора» → «Создать соревнование» (название, описание, дисциплина, дата, время начала/окончания, правила).
2. Вкладка «Задания» → добавить 3 задания (условие, баллы, примеры, файлы/ссылки) → «Опубликовать».
3. **Спортсмен** → «Соревнования» → карточка → «Зарегистрироваться». Вся информация — на одной странице: описание, даты, статус, задания, мои решения, таблица, правила.
4. Организатор нажимает «Запустить сейчас» (или старт наступает автоматически по времени) → спортсмен «Решать задачи» → код в редакторе **или** загрузка файла.
5. Организатор → «Проверка решений» → открыть решение → выставить баллы и комментарий → «Сохранить и следующее».
6. «Завершить» → «Подвести итоги» → фиксируется итоговая таблица (место, ФИО, баллы, баллы по задачам, время), протокол и CSV.
7. Результат появляется в **профиле спортсмена** (история участия, результаты) и **пересчитывает рейтинг** (с историей изменений).

Готовые демо-данные: завершённый «Тестовый контест по алгоритмическому программированию» (3 задачи, 10 участников, проверенные решения, опубликованные итоги), идущий «Кубок Дагестана — онлайн-тур» с решениями на проверке, предстоящие соревнования, черновик, очные соревнования с ручными результатами.

## Возможности

**Спортсмен:** регистрация и профиль (ФИО, город, учебное заведение, дата рождения, разряд, дисциплины) · каталог соревнований с фильтрами · заявка/отзыв заявки · контест-арена (условия, примеры, редактор кода с нумерацией строк, загрузка файла, лимит попыток, история отправок, таймер) · предварительная и итоговая таблицы · профиль с результатами, статистикой, графиком рейтинга · уведомления · приватность, выгрузка своих данных (JSON), удаление аккаунта.

**Организатор** (все страницы спортсмена + панель): дашборд с очередью проверки и подсказками · CRUD соревнований с жизненным циклом *Черновик → Опубликован → Идёт → Завершён → Итоги* (смена статуса автоматически по времени + ручной запуск/завершение) · задания с порядком и материалами · участники · ручная проверка решений с быстрыми баллами · подведение/отзыв итогов · ручной ввод результатов для очных соревнований · протокол и CSV · база спортсменов и подтверждение разрядов · справочники (дисциплины, уровни с коэффициентами, разряды с бонусами) · контент инфоцентра (новости, документы, FAQ) · связь с внешней платформой (Codeforces и др.).

**Инфоцентр:** новости, календарь соревнований, документы (положения, правила, официальные), полезные материалы, FAQ.

## Рейтинговая модель

```
R = Q + Σ P_i · D_i
P = 100·(N − M + 1)/N · K_ур · K_N · K_поля
```

- **Q** — бонус подтверждённого разряда (МСМК 300 … III юн. 8, б/р 0);
- **N** — число участников с результатом, **M** — место;
- **K_ур** — уровень соревнования (ЧР 2.0, всероссийские 1.6, межрегиональные 1.3, региональные 1.0, муниципальные 0.7);
- **K_N = 1 + 0.25·lg N** — массовость;
- **K_поля = 1 + (средний бонус разрядов участников)/1000** — сила состава;
- **D = 0.5^(дни/365)** — давность (вес результата падает вдвое за год).

Все коэффициенты редактируются в справочниках. Код — `rating/services.py`.

**Распределение мест в контесте:** сумма баллов (лучшая проверенная попытка по каждой задаче) → меньшее суммарное время получения лучших баллов → при полном равенстве место делится.

## Безопасность и конфиденциальность

- Пароли — PBKDF2-SHA256, валидаторы сложности; вход по логину/email с защитой от перебора (блокировка после 5 попыток на 15 минут) и выравниванием времени ответа.
- CSRF на всех формах, изменение состояния только через POST; `SECRET_KEY` генерируется при первом запуске и не хранится в коде.
- Строгая **Content-Security-Policy** (без inline-скриптов), `X-Frame-Options: DENY`, `nosniff`, Referrer-Policy, Permissions-Policy, COOP; `no-store` для персональных страниц; HSTS и Secure-cookie при `DJANGO_HTTPS=1`.
- XSS: пользовательский текст экранируется до применения разметки; ссылки — только http(s).
- Загруженные файлы хранятся **вне публичной директории** (`private_media/`) под случайными именами и выдаются только через представления с проверкой прав, как вложения, в песочнице CSP. Белые списки расширений и лимиты размеров.
- Решения видны только автору и организаторам (чужие ID → 404); черновики скрыты; ролевой доступ к панели.
- Защита CSV от formula-injection; honeypot в форме регистрации; cooldown между отправками.
- Конфиденциальность: согласие на обработку ПД с отметкой времени; email и дата рождения видны только организатору; скрытие учебного заведения и профиля; выгрузка и удаление данных (обезличивание результатов).
- Админка Django — по неочевидному пути (`DJANGO_ADMIN_URL`, по умолчанию `/control-room/`).

Для продакшена см. `.env.example`: задайте `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_HTTPS=1` и смените пароль организатора.

## Архитектура

```
config/         настройки, маршруты
core/           справочники, инфоцентр, уведомления, безопасность (middleware, отдача файлов), шаблонные теги, seed_demo
accounts/       пользователь (роли спортсмен/организатор), регистрация, вход, профиль, приватность
competitions/   соревнования, заявки, задания, решения, результаты; services.py — таблица и подведение итогов
rating/         история рейтинга; services.py — рейтинговая модель и пересчёт
panel/          панель организатора
templates/      шаблоны; static/ — CSS-дизайн-система, JS, шрифты
```

Единая цепочка данных: **Competition → Task → Submission → Result → User.rating / RatingHistory**.
